# Sunset Turquoise Mountain social media

This public repo hosts post media for Postiz. One folder per platform: instagram, facebook, tiktok, pinterest.

## Before any run
- The working rules live in the private Google Sheet "Sunset Marketing Tracker", tab "Run Rules" (spreadsheet id 1R4kjN6GmiegvnVYc8Kf96DU0NmudqgTlII4TBpzDGfg). Read it first. It covers link rules, wording, platform specs, Postiz settings and the pre-schedule checklist.
- The owner is in Central Time. Run `TZ=America/Chicago date` before scheduling, and ask if the date does not match the owner's request.
- Never schedule, publish, delete or edit a live post without the owner's explicit yes. Drafts are fine.

## Media conventions
- Upload media to Postiz with uploadFromUrlTool from public URLs (this repo or Shopify product images).
- TikTok images must be 1080px or less on the short side. Upload with adjust=true and wait until the media status is ready.
- Instagram and Facebook feed: 4:5. TikTok and Reels: 9:16. Pinterest: 2:3.
- Name new files by platform and date, for example `instagram/2026-11-04-carousel-1.jpg`.
- Do not put private business details, names or financial figures in this repo, because it is public.
